# L'Énigme de la Plume

Cahier de jeux (PWA) à faire avant le spectacle *Cyrano*, librement adapté de *Cyrano de Bergerac* d'Edmond Rostand.

- Aucune donnée n'est collectée ni envoyée : tout reste dans le navigateur du téléphone (localStorage).
- Fonctionne hors ligne après la première ouverture.
- Site statique : `index.html`, `app.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
